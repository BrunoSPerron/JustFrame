An expressive control layout designed for **maximum mechanical depth** with **clean player expression**.

---

## 🔘 Button Layout (6 Buttons)

| Button                  | Function                         |
|--------------------------|----------------------------------|
| **Step**                | Directional movement / evasion   |
| **Guard**               | Manual guard + counter timing    |
| **Punch**               | Primary attack                   |
| **Kick**                | Secondary attack                 |
| **Low Action Modifier** | Enables crouching / low moves    |
| **High Action Modifier**| Initiates jumps / high moves     |

- **Modifiers** combine with **Punch/Kick/Step/Block** to generate specialized actions.
- L is also used as crouch
-

## Input Notation

- **Directional Movement:** ← ↑ → ↓ ↖ ↗ ↘ ↙  
- **Inputs:**
  - `P` = Punch  
  - `K` = Kick  
  - `G` = Guard  
  - `S` = Step  
  - `H` = High  
  - `L` = Low  

**Notation Format:**  
- Combine direction + input: `→HP` = Forward High Punch  
- Separate each distinct input in combos with a comma: `P, HP, →LK`
- Classic input like  ↓↘→ are rare, maybe nonexistent. It map to a lateral movement which will probably feel strange for experienced fgc members

---

## 🎯 Directional Input

- **4-way input** (Forward, Back, Up, Down) + Diagonals
    - Drives **ground movement**: walk, dash, backstep
    - Combined with **Step** for sidesteps, slides, rolls
    - Used with modifiers for **8-directional jumps**

---

## Design Intent
- **No traditional light/medium/heavy** attack tiers.
- Instead, **context + timing + modifiers** define move behavior.
- Promotes **intentionality**, not button mashing.
