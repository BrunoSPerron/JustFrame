An overview of the core **Rock-Paper-Scissors (RPS) loops** that define high-level decision-making across the game's systems. Each triangle represents a self-contained interaction space with clear risk/reward dynamics.

---

## 🎯 Counter-System Triangle (Neutral / Reaction RPS)

| Option                | Beats                                 | Loses To                         |
|-----------------------|----------------------------------------|----------------------------------|
| **Attack**            | Empty Block / Mistimed Counter         | Well-Timed Counter (Block Input)|
| **Block / Counter**   | Attack                                 | Throw / Guard Break / Feint     |
| **Throw / Feint**     | Counter / Passive Block                | Raw Attack                       |

- **Focus**: Reaction timing, conditioning, and reading habits in neutral.
- **Risk/Reward**: High reward for counters, but punishable by mixups.

---

## 🛌 Wake-Up / Okizeme RPS

| Option                    | Beats                   | Loses To               |
|---------------------------|--------------------------|------------------------|
| **Wake-up Action**        | Passive Wait             | Meaty Read             |
| **Meaty / Read**          | Wake-up Attack / Roll    | Delay / Fake-out       |
| **Delay / Fake-out**      | Meaty Attempt            | Active Wake-up Options |

- **Focus**: Timing, option coverage, and initiative.
- **Risk/Reward**: Wake-up is a mindgame, not a reset to neutral.

---

## ☁️ Aerial Engagement RPS

| Option                    | Beats                              | Loses To                            |
|---------------------------|-------------------------------------|-------------------------------------|
| **Air Attack**            | Static Defense / Ground Anticipation| Anticipated AA / Air Counter / Block|
| **Air Block / Counter**   | Air Attack                          | Empty Jump / Bait                   |
| **Empty Jump / Feint**    | Defensive Reads                     | Air Attacks                         |

- **Focus**: Vertical control, commitment, and anti-air logic.
- **Risk/Reward**: Jumping is powerful but demands prediction.

---

## 🌀 Balance Transfer / Stagger System RPS *(Situational)*

| Option                          | Beats              | Loses To                         |
|----------------------------------|---------------------|----------------------------------|
| **Aggressive Follow-Up**        | Passive Defense     | Timed Block Input (Reversal)     |
| **Timed Block (During Stagger)**| Attack (Trades Control)| Feint / Throw / Delay        |
| **Feint / Delay / Throw**       | Counter Attempt     | Aggression / True Blockstrings   |

- **Focus**: Precision defense and frame-awareness during stagger windows.
- **Risk/Reward**: High for both sides, encourages mechanical mastery.

---

## Notes
- Each triangle serves a **different phase of engagement**: neutral, wake-up, air, or reactive defense.
- Overlaps exist—systems are **modular but interconnected**.
- Expand or collapse each loop depending on matchup, character tools, and reads.
