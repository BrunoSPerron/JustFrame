# 🧠 Concept Overview

The **Okizeme system** ensures that knockdowns are **tactical moments**, not passive punish windows. Even while downed, the defending player is expected to remain **engaged, reactive, and thoughtful**. The system supports varied recovery choices and timing-based mechanics that fuel a dynamic mind game between both players.

Knockdowns are designed to **maintain game momentum** while still offering the defender strategic counterplay.

---

# ⚙️ Mechanic Details
## 🔄 Recovery Options
- Upon being knocked down, players can select from **multiple recovery types**, including:
    - **Directional tech rolls** (forward/back/side).
    - **Neutral get-up** (standard rise with no movement).
    - **Delayed get-up** (adds timing unpredictability).
    - **Character-specific wakeup options** (e.g., invulnerable wakeup kick, evasive maneuver).

## ⏱️ Input Timing at Moment of Knockdown
- A **precise input window** at the moment the character hits the ground allows:
    - Access to enhanced or alternate recovery options.
    - Improved positioning or frame advantage on wake.
    - Adds **skill expression** to wakeup defense.

---

## 🧮 Balance-Linked Wakeup Economy
Wakeup options are tied into the [Balance](Game%20Design/Mechanics/Balance.md) system to create meaningful tradeoffs:

|Option|Balance Impact|Strategic Use|
|---|---|---|
|**Quick Rise**|Costs Balance|Fast but unstable recovery.|
|**Neutral/Delayed Rise**|Regains Balance|Safer, stabilizing choice.|
|**Wakeup Attack**|High Balance Cost|Offensive commit on wake.|
|**Back Roll**|Neutral Balance|Resets spacing safely.|

# 🎯 Design Intent
- **Keep Both Players Engaged**: The attacker isn’t just running a flowchart; the defender isn’t just holding down-back.
- **Avoid Looping Disadvantage**: Prevents toxic pressure cycles by giving the defender real agency post-knockdown.
- **Encourage Tactical Variety**: Forces both players to read each other's intentions with every wakeup situation.
- **Leverage System Synergy**: Ties directly into [Balance](Game%20Design/Mechanics/Balance.md), [Stagger](Game%20Design/Mechanics/Stagger.md), and movement mechanics to create layered, non-linear outcomes.
    

---

# 🔗 System Synergy

- **Balance System**: Wakeup choices directly affect or are affected by Balance values.
- **Stagger System**: Some knockdown types result from stagger states, influencing available wakeup timings or options.
- **Movement System**: Tech rolls and get-up directions interface cleanly with the game's high-mobility movement design.
- **Attack Orientation**: Wakeup state and options can vary based on the direction or type of the knockdown-causing move.
