# Character Archetypes

## High Compatibility Archetypes – Best

| Archetype             | Summary                                              | System Synergy                                                                 |
|-----------------------|------------------------------------------------------|---------------------------------------------------------------------------------|
| Brawler / Pugilist    | Tight pressure, strong fundamentals                  | Game’s core! Depth comes from spacing, stagger pressure, and balance control   |
| Martial Artist        | Realistic, fluid combos, flexible timing             | Strong synergy with counter timing and animation blending                      |
| Rushdown              | Constant pressure, thrives in close range            | Stagger becomes pressure loop. Fast movement, short-range normals              |
| Mixup                 | Ambiguous high/low or left/right setups              | High/low modifier system + jump directions enable strong movement-based mixups |
| Kickboxer / Taekwondo | Focus on legs, long active frames, mobility          | Fits perfectly with jump stances and high/low play                             |
| Slippery / Elusive    | Dodges, counters, bait-and-punish                    | Ideal use of movement, tech, and counter system; excels at balance reversal    |
| Heavy / Hitter        | Slow but devastating; wins through knockdowns        | Leverages knockdown power + positionals. Risky but thematic                    |
| Counter-Fighter       | Weak offense, punishes mistakes                      | Counter window and balance reversal make this archetype shine                  |
| Weapon User           | Uses knives, claws, nunchaku                         | Adds flair, extended normals, unique hitboxes                                  |
| Stance / Flow-Based   | Adapts styles mid-fight                              | High/low + direction input scheme supports this directly                       |
| Style-Switcher        | Multiple modes/forms with unique movesets            | Synergy with modifier buttons and jump stances—rewards mastery                |

## High Compatibility Archetypes – Need Adaptation

| Archetype             | Summary                                              | Notes                                                                                          |
|-----------------------|------------------------------------------------------|-------------------------------------------------------------------------------------------------|
| Glass Cannon          | Fragile, explosive; wins fast or dies fast           | Works if framed as fast with low balance and poor tech options                                 |
| Charge                | Holds for strong special attacks                     | Charge may feel clunky. Consider moving charge + gravity control in air                        |
| Setplay               | Space control via traps/delays                       | Could use air-based or movement-triggered traps (e.g., monke jump on sticks)                   |
| Unorthodox / Gimmick  | Odd hitboxes/movements, rule-breaking                | Include as system stress-test, but keep within movement theme                                  |

## Niche / Uncommon Archetypes – Best

| Archetype             | Summary                                              | System Synergy                                                                 |
|-----------------------|------------------------------------------------------|---------------------------------------------------------------------------------|
| Parry Specialist      | Read-based defense, counters                         | Timing guard and balance reversal support this elegantly, even with poor offense |
| Rhythm / Flow-Based   | Tempo-sensitive; rewards rhythmic use                | Rewards stylish, consistent timing; very skill-intensive                        |
| Stance Trap           | Deceptive stance switching to bait reactions         | Button scheme makes this archetype highly viable                               |
| Feint Specialist      | Fakes, delays, cancelable startups                   | Ties into movement, bluff windows, and pressure mindgames                      |
| Aerial Dominator      | Air-heavy, high mobility and options                 | Works if air tools are commit-heavy and tech/block system supports risk        |
| Floormaster           | Ground-based with great mobility                     | Complements grounded footsies and balance play                                 |

## Niche / Uncommon Archetypes – Need Adaptation

| Archetype             | Summary                                              | Notes                                                                                          |
|-----------------------|------------------------------------------------------|-------------------------------------------------------------------------------------------------|
| Glass Mobility        | Very fast, low damage, fragile                       | Could be reframed as mobility-control archetype with evasive tech                              |
| Copycat               | Mimics or steals opponent’s moves                    | Breaks minimalism—use cautiously if at all                                                     |
